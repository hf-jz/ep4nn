## 1. H-JEPA（arXiv 2610.06805）

已核要点（摘要原文）：每层在自己的潜空间预测更远的未来；规划自上而下，高层预测成为低层子目标；
Visual AntMaze 上三层把成功率从 18% 提到 73%，且**规划算力更少**；用 SIGReg 防表征坍塌；
Push-T 上两层优于三、四层（层数不是越多越好）。

对 ep4nn 的三条可用：

1. **读出不动可能就是表征坍塌。** 我们的症状是"群体状态对输入不敏感、读出只动 0.019"，
   与 JEPA 要防的 collapse 是同一类失败：编码器把所有输入压到同一个向量，预测误差很小但没信息。
   这给出一个**便宜且可证伪的检查**：算 302 状态的有效秩/协方差谱。若有效维度接近 1，
   那问题不是"神经元不够"，而是"状态空间塌了"——加神经元只会加出更多塌陷的副本。
2. **子目标端口 > 直接动作读出的接口设计。** 低层不该直接对最终答案负责，而应付"把状态推到某个子目标"。
   ep4nn 现在的读出是"直接出动作"，这在高维任务上天然不敏感；加一个 subgoal 端口是结构改动，不是调参。
3. **层数由时间跨度定，不由"感觉复杂"定。** Push-T 的反例正好支持我们的证据闸门：深度也要被证据批准。

不可照搬：JEPA 端到端反传训像素；ep4nn 是局部可塑性 + 均衡求解。能搬的是**接口与正则**，不是训练法。

争议点（公众号层）："LeCun 创业交卷 / AMI 融资 10.3 亿美元、投前 35 亿"——arXiv 页面只有作者与摘要，
**这条融资与归属未核**，不要引用为事实。

## 2. 大脑真正的"基本计算单元"

已核要点：稳定的是任务相关低维投影 z=H(x)（不同微观状态 x 可映射到同一 z），不是某个固定结构；
单个 L5 锥体细胞（含 NMDA 动力学）需要约 5–8 层 TCN 才能在毫秒尺度近似（Beniaguev/Segev/London 2020）。

对 ep4nn：

1. **评价口径**：不要再比"神经元状态是否重复"，要比"任务相关投影是否等价"。这直接改我们的收据字段。
2. **节点粒度是被低估的旋钮**：ep4nn 每个神经元是单 patch column（线性求和 + 泄漏），
   而生物节点内部有树突非线性。若读出不动是因为节点表达力不足，那么"加节点"是错的解法，
   "给节点加一个树突非线性"才是对的那个量级更小的改动。
   这是一条**可先做、成本最低**的对照实验。
3. 警告："一个生物神经元 = 8 层网络"是特定任务上的拟合近似，文章自己也这么说；不可当换算率用。

## 3. 纺锤体神经元（Nat Commun 17:6330）

已核要点：SPN 有独特转录组（ADRA1A/SULF2 富集）、轴突从基树突干发出、内在兴奋性更高、
对弱输入产生延长的持续放电（簇状 12.9–15.6 个 AP，瞬时频率 80–127 Hz）；除 L5 外也见于 L4；
在额叶/颞叶找到，顶叶没有；稀有但成簇（约 1.75 个/mm³）。

对 ep4nn：

1. **"扩张 = 加类型，不是加数量"** 是对我们增长假设最直接的一击：如果 302 个同款节点解决不了，
   加 3000 个同款节点也解决不了。增长的候选单元应该是新 motif（持久放电 / 高增益 / 双稳），
   而不是同构节点的复制。这与我们"1200 次拒绝"的结论同向：**缺的是结构，不是数量**。
2. **持久放电 motif 正好补我们的短板**：延迟/工作记忆类任务需要跨时间保持的状态，
   而我们目前只有泄漏积分（decay 0.8），没有双稳/持续单元。SPN 给了一个有生物学依据的候选单元。
3. 注意：SPN 的"支持认知"仍是推断（原文说功能未解决），别把它写成已知功能。

## 4. 学习的神经环路（海马→基底节→小脑→前额叶）

对 ep4nn：给"半冻结"一个可操作的划分，但**不可当事实照搬**。

可用的一条：不同子系统用不同的可塑性时间尺度——情景快存（海马样，全可塑）、
策略固化（基底节样，冻结）、误差校准（小脑样，长期保持可塑）、门控（前额叶样，慢调）。
我们的"半冻结"可以直接落成：**冻结策略块 + 保留误差校准块可塑**，而不是笼统地"冻结权重、保留调质"。

辩证：文章把基底节写成只管习惯固化，这是过度简化（基底节同时参与目标导向选择）；
"机器学习=一次性参数拟合"是稻草人；功能定位的边界比它写的模糊得多。引用时只引"分层时间尺度"这一层，
不引具体分区结论。

## 5. 脑网络的基本单元（Nodes and Edges）

对 ep4nn：**协议层**有用，科学层无新信息。

可用的一条：结构连接 / 功能连接 / 有效连接是三种不同断言。我们现在的说法
"读出不动所以拒绝增长" 是从一个**结构模型**推**有效连接**结论——这必须写清楚，
否则就是跨层断言。收据里加 `connectivity_kind` 字段，成本一行代码，挡住一类过度声称。

## 6. intrinsic manifold（Sadtler 2014，Nature 512:423）

已核要点：85–91 维神经空间中存在约 10 维内在流形；流形内的新映射几小时内可学会，
流形外显著更难；结论是"现有网络结构约束学习"，且这个约束无法用单神经元分析解释。

对 ep4nn：**这是九篇里对我们最有用的一个结果**，因为它把用户问的"问题复杂度"变成了可测量：

- 复杂度 = 目标活动模式到当前内在流形的距离（不是神经元数、不是 MDL、不是主观分级）。
- 增长若只是扩大同一流形（更多同款节点），**不会**缩短这个距离 → 必然失败。
  这解释了 1200/1200 全部拒绝：不是闸门太严，是增长提案本身选错了方向。
- 可执行判据：测 302 状态的 PCA 谱 → 取解释 90% 方差的前 k 维 → 把"目标答案模式"投影上去 →
  残差占比就是"流形外距离"。残差大 → 允许增长，但只允许**新 motif**；残差小 → 不许增长，只许学。

这与第 3 篇（加类型不加数量）、第 1 篇（层数与子目标）拼成一条完整的增长判据链。

## 7. RSI（递归自我改进）

未逐个核原始论文，但框架可用，且与我们的"自主决策"要求直接相关：

- 有界自我改进（对固定评估器优化）有实证；严义 RSI（评估器/改进器也自改）无实证。
- 四问检查表：信号对不对 / 有没有新东西 / 采不采得到 / 吸收了会不会丢。
- 最危险的失败模式：评估器被改进过程自己改掉。

对 ep4nn：把"闸门不可改"写成**设计不变量**——增长生成器可以演化，判定它是否该增长的证据闸门不能。
我们现在的实现已经符合（裁决层独立），但**没有写成不变量**，后续改动容易破坏。建议进 `docs/创新点.md`。
四问检查表可以直接做增长提案的 checklist（尤其"有没有新东西"：同款节点复制 = 没有新信息）。

## 落地建议（按成本排序，都是可证伪的）

**A0（成本≈0，先做）流形诊断**：算 302 状态 PCA 谱、有效秩、读出投影残差；
写进 `probes/` 作为新探针。判据：有效秩 ≈1 或残差远大于读出位移 → 结论改写成
"瓶颈是表征坍塌/流形外距离"，而不是"神经元数不足"。

**A1（成本低）节点表达力对照**：固定 302 节点，只给节点加一个树突式非线性（两房室/局部饱和），
重跑同一工作点。若读出位移从 0.019 显著上升 → 证明"缺的是节点表达力，不是节点数"，
这条比任何增长实验都便宜且更能定方向。

**A2（成本中）一个新 motif 替代更多同款**：按 SPN 的持续放电特征，加一个双稳/慢变量单元，
作为增长的**唯一**候选。判据用 A0 的流形外距离 + 读出位移 + 冻结消融必要性。

**A3（成本≈0，协议）三处收据字段**：
  - `connectivity_kind: structural | functional | effective`（防跨层断言）
  - `manifold_distance: k, residual_ratio`（把复杂度变成数）
  - `gate_frozen: true`（RSI 不变量，闸门不可被增长过程改）

不做：把 H-JEPA 的反传训练、RSI 的"AI 改 AI"整套搬进来；公众号的融资/产品叙事；把 SPN 的功能当已知。
