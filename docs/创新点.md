# ep4nn 主要创新点

六条。每条都写：**是什么 / 与现有做法的差异 / 证据 / 状态**。后面单列"明确不宣称"的部分，避免自欺。

---

## I1 需求驱动的结构增长判据：**读出不可分 = 容量信号**

**是什么。** 增补结构的触发量不是训练损失、不是梯度、也不是路由器打分，而是：
**同一个当下输入、不同情境，脑子的答案（读出群体活动）几乎平行**（|cosine| > 0.85）。
可分辨性才是目的，稀疏只是手段——这条口径直接来自 Cadence 自己在果蝇上的实测（单一全局增益下两个气味的
Kenyon 细胞码 cosine 0.98，加"按细胞类别增益"后降到 0.32；`docs/cadence-判定.md` §3.2 D）。

**与现有做法的差异。**
| 做法 | 粒度 | 触发 | 我们的差异 |
|---|---|---|---|
| MoE / conditional computation | 权重级（选专家） | 学的 router | 我们改的是**结构**（增神经元/增突触），且判据是可分辨性 |
| NAS / 演化 | 结构级 | 离线、跨代 | 我们在**生命内**、由"相悖情境"触发 |
| 剪枝 / dropout | 结构级 | 事后或随机 | 我们只增不减，且必须过成效裁决 |
| Cadence 默认 | 结构固定 | —— | 其 worm 示例原文 "nothing else can grow"；增长被明令禁止 |

**证据。** `ep4nn/grow.py` 的规则 1–2；实测 1200 tick 无假动作（`docs/实测台账.md` §6）。
**状态。** 机制已验证；**一次成功的增长尚未出现**（受 I6 上游阻塞，见 `方案.md` Phase 0）。

## I2 把 Cadence 的"拒绝语义"从数值层扩到**结构层**

**是什么。** Cadence 的核心契约之一是"算不出来就不发动作"（残差不合格即拒绝，且拒绝不改状态）。
ep4nn 把它推到结构上，两级：

1. **前提闸（refuse-to-grow）**：当"答案根本没动"（读出 spread < 0.05）时，**拒绝增长**——
   这种情况下任何容量都救不了碰撞，增长是错的修复方式。实测 1200/1200 次拒绝并记录 `no_response`。
2. **成效裁决（keep-or-rollback）**：增长后必须重测**同一批碰撞**，余弦下降 ≥ 0.02 才保留，
   否则整体回滚并计一次失败。实测另一版（无前提闸）30 次增长 30 次回滚。

**与现有做法的差异。** 现有动态结构方法基本只问"长了以后变好了吗"，很少把"**增长的前提是否成立**"
做成显式闸门；而把"前提不成立"和"容量不足"分成两类失败，是这一层的全部价值——
它把无效结构变更的花销从"训练预算"降到"一次测量"。

**证据。** `grow.py` 的 `min_response` 闸与 `try_grow`；两次 demo 的对照输出（30 回滚 vs 1200 拒绝），
见 `实测台账.md` §6。
**状态。** 已验证（机制层）。

## I3 低维结构生成器 + **差异驱动布线**（13 个基因 ≪ |E|）

**是什么。** 生成新结构的不是一张边表，而是 13 个基因（`GrowthConfig`）：每个新神经元按
度分布布线（`degree`/`degree_jitter`），伙伴**优先取自"差异细胞"及其一跳邻域**（`locality`），
符号按图的兴奋比例（`excitatory`），默认**成对 reciprocal**（`reciprocal`，保住 EP 的梯度契约），
并且**必须能到达读出**（`to_readout`）——否则数学上不可能改变答案。

**与现有做法的差异。** 随机生长、随机剪枝、dropout 都不带"信息驱动"；NAS 搜的是结构但不告诉你
**哪条差异**要求这条连接。这里的差异向量 `|code_a − code_b|` 就是"该接谁"的唯一来源，
而它同时满足硬约束 **dim(生成器) ≪ |E|**（否则结构可塑退化成隐式权重学习，稀疏/可解释/低功耗优势全废）。

**证据。** `grow.py` 的 `GrowthConfig`、`_difference_cells`、`_grow`（含 key 顺序迁移 efficacy）；
无延迟/无位置时用**跳距**（一跳邻域）当"空间"的代理——这也是 Cadence 线虫示例里已有的做法
（按"到感觉细胞的突触距离"排序决定 tick 内/跨 tick）。
**状态。** 实现已验证；**成效待验证**（受 Phase 0 阻塞）。

## I4 四层时间尺度 + 三级触发判据 + **两层价值**（外生选择压力 / 内生价值尺度）

**是什么。** 把"持续学习系统"拆成四层，每层改什么、何时允许改，都是判据而不是旋钮：

| 层 | 时间尺度 | 改什么 | 触发判据 |
|---|---|---|---|
| 快 x | ms–s | 当前情境的推断/沉降 | 每步 |
| 中 z | s–min | 回路实例与局部参数 | 三因子实时更新，但**投影到慢层信任域内** |
| 慢 μ | h–天 | 规律 | **相悖事件**：投影残差 r = ‖(I − P_{T_μ})δ‖ 超阈值 |
| 代际 g | 代 | 价值尺度（动机参数） | **跨多个慢层事件仍解释不了**，或选择压力本身变更 |

关键区分：**选择压力常是外生的，价值尺度本身往往是内生产物**（演化/文化选择塑造的可遗传参数）。
工程后果：价值尺度必须参数化、可遗传——而这正是 Cadence 现成件（`genes(space)`、
`ArousalConfig.space()`、`evolve`；MANIFESTO 强制"每个设计数字都成 gene 并保留 founder 对照"）。

**与现有做法的差异。** Cadence 是三层的且价值尺度是手设常量；RLHF 的价值是外生注入的（于是奖励劫持是
内生属性而非 bug）。这套结构把"何时改价值"也变成判据，并显式承认**价值尺度内生 ⇒ 上限 = 代理量**，
除非 fitness 换成不自证的东西（物理存活/能量/复制，Patch World 是现成范例）。
**证据。** `cadence-判定.md` §7；Cadence API 引用见 `方案.md` Phase 3。
**状态。** 设计成立，未实现。

## I5 EP 成立性的**运行时前置检查**：局部收缩证书不是性能优化，而是梯度语义的前提

**是什么。** 把 equilibrium propagation 的理论条件（能量存在 / 自由相收缩到唯一稳定分支 / 小扰动）
做成运行时判据，并在真实图上量出来：线虫 302 图上**全局最坏界 q = 88（292/302 行 ≥1，无证书）**，
而**当前状态活动集**上局部谱半径 0.529、加权见证 α = 0.696（有证书）。

**与现有做法的差异。** EP 文献里这些是假设；这里变成"这一拍到底算不算梯度"的可测前提，
并且它给出的 settle 预算把 Cadence 的"算不动就拒绝"改造成"有预算 + 上一动作兜底"。
**证据。** `probes/probe_certificate.py`；`实测台账.md` §4。
**状态。** 已在测量层验证；接进库内热循环未做。

## I6 生态口径统一：同一份收据格式

**是什么。** 8 个果蝇脑项目各写各的边界、互不可比。ep4nn 用同一张表要求每个结果回答：
**名义规模 / 实际运行规模 / 动力学模型 / 是否闭环 / 前提是否成立 / 每次决策的算力与能耗**。

**证据。** `果蝇生态审阅.md`（该表已抓出：名义 16.5 万 vs 浏览器 demo 跑 850 神经元的 MiniFly、
只拉 LPLC2→DN 子图却写"16.5 万神经元、无需训练用进化权重"等）。
**状态。** 文档层已建立。

## 明确不宣称（避免把既有工作算成自己的）

- **稀疏激活**不是我们发明：果蝇图在每种刺激下活跃 < 1% 是 Cadence 的实测；MoE/early-exit 是工程既有。
- **三因子局部学习、互补学习系统（CLS）、睡眠重放**都有前例（CLS 1995；Cadence 的 record/sleep 已带收据 0.55→0.80）。
- **gene + 选择**是 Cadence 已有机制（`Genome`/`mutate`/`evolve`），我们只是把它接到"价值尺度"和"结构增长"上。
- **规模 ≠ 能力**：therealfly 用 16.5 万神经元 + 真实身体 + 完整接线做出的是"打乱接线同样复现的失控振荡"。
  ep4nn 不主张"神经元数量"是能力变量。
