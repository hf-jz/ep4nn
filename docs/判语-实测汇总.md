# 判语 · 实测汇总（2026-10-20）

这份文档取代散落在 `实测台账.md` §11–§18 里的叙述，只回答一个问题：
**"generalized 类脑结构 + 自适应扩规模"在 c302 线虫接线上，有没有实验支持？**

答案：**八条假设，七负一正**。正的这一条不是"加神经元"，而是"槽位随输入宽度"。

所有数字都来自本仓库探针，**每个结论都有 `probes/*.py` 与 `docs/assets/*.json` 兜底**，可重跑。

## 二、唯一可用的正面规律

> **记忆槽位跟随输入宽度与 motif 种类，不跟随神经元数。**

- §13：61 维输入 → 36 个有效维；14 维输入 → 约 16 个槽位。
- §18：hidden 从 88 加到 280（3.2×）没有增加槽位。
- §17c：记忆的载体是吸引盆（终态一维二分叉），不是突触数；因此"长更多同款突触"不产生新盆。

对应到立项时的原始问题（"何时加、加多少"），可执行的形式是：

| 想提升什么 | 该动什么 | 不该动什么 |
|---|---|---|
| 记忆槽位 | 输入通道数、motif 种类（新盆） | hidden 神经元数 |
| 决策极性 | 符号/权重层：符号已对，缺**逐突触强度**（全局 GABA 增益只到 ρ=0.83、不翻转） | 增益旋钮、读出、规模、分室 |
| 规则合取（上下文×刺激） | **第二个房室**：规则乘性门控阈值（§22，1.000 vs 机会） | 把规则当加性输入（分离度更大但学不会）、全局门控强度过大 |
| 分级精度 | 读出秩（但要接受 MAE 变差） | 神经元数 |
| 长期记忆 | 不动（已经免费，128 步不衰减） | 慢变量（τ=50 反而更差） |

## 三、已证伪清单（别再重做）

1. 行归一化权重下"提高增益能提升表现"——提高增益只是拿状态维数换读出位移（§11）。
2. 提高 sigmoid 陡度——会把状态压得更死（§11b）。
3. 电位记忆 `leak`——三档完全无差别（§11b）。
4. per-neuron bias/gain 抖动——读出 PR 升但承载方差从 22% 掉到 6–13%（§11b）。
5. 换 10 细胞读出——PR 升 4.5×，情境可分性不升（§12/§13）。
6. 慢变量 `Adaptation` τ=50/200 延长记忆——τ=50 在 k=16 反而从 0.825 掉到 0.660（§17b）。
7. 干扰型难度抬高所需秩——平坦（§16）。
8. 用"解码率 + 跨集迁移"在冻结基质上证明抽象效价——三个指标同时饱和（1.000/1.000/0.55），无分辨力；标签是驱动的单调函数，指标只是复读 §5（§23）。
9. 用钙阈值可塑性换准确率——θ=0.6 拒绝 56–64% 更新，3 个 seed 准确率全部下降（0.71–0.78 → 0.54–0.62）；阈值买的是可解释性，不是性能（§24）。

## 四、这套结论的边界（必须一起引用）

- 基质是 **c302 速率模型 + 固定接线 + 预测符号**。符号来自递质预测而非实测，91% 兴奋，这是 §14 判否的直接原因。
- 线虫的"任务"是我按文献价态定义的（吸引物→前进、避害→后退），不是实测行为。
- 时间刻度是积分步（dt=0.2），不是毫秒；horizon 数字不能换算成生物时间。
- §18 的输入固定 14 维，槽位上限被它卡住；真正的"规模→槽位"曲线需要 input 与 hidden 同步缩放（未做）。
- 所有实验单机 CPU、单进程、单 seed 起步；§18 已做三 seed 复核，其余各条为单 seed（配对任务、冻结输入）。

## 五、会改变判语的三件事（按成本排序）

1. **实测符号/权重**：拿到 GABA 能细胞的生理标定（哪怕少量），重跑 §14。若出现极性翻转，第 4 条翻案，整个"决策层"论证要重写。
2. **input 与 hidden 同步缩放**：重跑 §18。若槽位随两者一起上升，则"规模"以"输入宽度"的形式重新有效。
3. **换基质**：可塑符号（STDP/三因子）或分室节点。这是 §14 引的 JEPA/SPN 线索指向的方向，也是唯一能把"结构族"从"固定接线"里解耦的路径。
   **分室已试（§22）：成立但作用域有限**——规则门控阈值能解合取（1.000 vs 机会），不改变极性。可塑符号（P3 钙阈值）仍未做。
