# ep4nn 论证严谨性审计

审计对象：`docs/paper/ep4nn.tex` → `docs/ep4nn.pdf`（2026-10-15 版），以及它引用的全部探针与数据。
方法：不读文风，只重算。每个数字回到产生它的探针重跑一遍，每条推断问"这条是定义、是实测、还是推断"。
新增探针：`probes/probe_audit_claims.py`（把三条原本是推断的主张变成测量）。

## 一、判语（先说结论）

**5 个创新点里 2 个的论证是严格的（数学链条闭合），2 个是"实现/计数"型事实但附带了一条未证明的推断，1 个原稿数字有实质缺陷。**
更严重的是原稿存在**一处跨全篇的内部不一致**：前提扫描用的是**丢掉接触计数的图**，而成本表、证书表、增长 demo 用的是**带计数的图**——同一篇论文里两个不同的基底。修正后**负结果更强**（45 个工作点里 0 个过闸），代价是所有数字重跑并全线更新（论文、站点、图、文档）。

一句话：**结论方向没错，但原稿的"证据链"有一处地基级错误和四处过度表述，现在已修；剩下的缺口属于"尚未测"，不是"测错了"。**

### C3 的数学链条（本次补全的部分）

- 迭代：`v ← (1-dt)v + dt(W s(v) + stim + bias)`（`np/neuron.py:7`），雅可比 `J = (1-dt)I + dt·W·diag(s'(v))`。
- 因 `s' ≥ 0`、`dt ≤ 1`，`|J| ≤ K = (1-dt)I + dt|W|diag(s'(v))`（逐元素），非负矩阵谱半径单调 ⇒ `ρ(J) ≤ ρ(K)`；`Kh ≤ αh` 由 Collatz–Wielandt 给出 `ρ(K) ≤ α`。实测 `majorant_dominates=true`、`ρ(J) ≤ ρ(K)` 在 5 个状态上全部成立。
- 停机判据桥：残差 `r = -v + Ws(v) + stim + bias` ⇒ 一步位移 `Δv = dt·r`，实测比值恰为 `1/dt = 2.0`（dt=0.5）。原稿没有这条桥，等于把"位移收敛"当成"残差判据收敛"。

## 四、缺口关闭记录（本轮全部闭环）

审计提出的 7 条缺口逐条处理，处理方式是测量与代码，不是措辞。

| 缺口 | 原状 | 处理 | 结果 |
|---|---|---|---|
| G1 证书是数值界 | `eigvals` 估计 + 宽松的加性迭代见证（α=0.696） | 见证改为幂迭代的 Perron 向量；不等式以 one-ulp 外向舍入计算并 `assert`（Kolmogorov/Collatz–Wielandt） | **认证界 = ρ，六位小数一致**：默认 efficacy **0.529065**，声明工作点 **0.931159**；0.696 那条是宽松界，已删 |
| G2 证书只在单状态 | 一个状态 | 扫 3 个工作点 × 4 个驱动幅度 = 12 个状态 | 12/12 均 < 1，**最差 0.941**；域内每状态都出认证界 |
| G3 前提门规格错（聚合 spread） | 用聚合 spread 判前提 | 改为**声明对**的相对位移 `‖Δa‖/max(‖a‖)`，门限 1e-3（区分"同一对象"与"差一点"） | 同一批答案：聚合量 0.0083（拒绝）vs 成对量 0.0316（放行）——**门开在正确的量上** |
| G4 增长从未被行使 | `kept=0` 且 `refused=1200`，只有拒绝 | 换读出族（10 种声明）+ 修正门限后重跑 | **90 次增长尝试（3 读出 × 30），90 次回滚，0 保留**；判据层完成 90 次裁决——功效仍为负，但机制被行使 |
| G5 对照单种子 / 无 baseline | 1 个随机图 | 5 个种子 | ρ 0.6155–0.6192（均值 0.6174），sweeps 全为 32；"13 基因"改为**计数事实**并明写"未测 dense-search 对照" |
| G6 引用未核 | Shiu/Vaxenburg 软引；BANC 数字归属不明 | 逐条联网核 | Shiu = Nature **634:210–219 (2024)**；Vaxenburg = Nature **643:1312–1320 (2025)**；BANC 自身 ≈16 万神经元 / 1.99 亿突触，**150,802 / 1,877,099 是库自身过滤后的航道计数**（原稿混用，已改） |
| G7 无复现对比 | 未做 | `repro_check.sh`（快照→重跑→`diff -rq`）、`receipt_determinism.sh`（两次全跑 diff）、PDF 固定 `SOURCE_DATE_EPOCH` 两次构建 | **产物一致；收据逐字节一致；PDF 逐字节一致** |

修复过程中**新发现并修掉**的缺陷：

- **D9 宽松见证当证书**：原 `0.696` 来自 `h ← Kh + 1` 的加性迭代（收敛到 `(I-K)^{-1}1`，是合法见证但很松）。已换 Perron 见证，证书收紧到 ρ 本身。
- **D10 `grow.py` 的读出参数未接线**：`demo(readout=...)` 只改了签名，三份收据字节相同（`readout: ['forward','reverse']`）；且加载器没有 cell-class 群体，`class_sensory` 直接 `KeyError`。两处已修，三份收据现在真的不同。
- **D11 绝对量 + 细胞平均掩盖差异**：成对量若取"跨读出细胞的平均绝对差"，会被大多数不动的细胞稀释（sensory 读出 0.0041，反而低于默认读出），据此会把"差 1%"误判为"没动"。已改为**相对范数**量。
- **D12 "整体状态必然可分"是错的**：实测 whole-state（302 细胞）collision **0.9997**——驱动细胞饱和，整状态同样不可分。该表述已从论文与站点删除。
- **D13 归属漂移**：BANC 的 150,802/1,877,099 被当作 BANC 发布口径；实为库过滤后的航道计数。已按来源分开表述。

## 五、剩下三点的闭环（新增探针 `probes/probe_closure.py`）

### ① 增长的功效 —— 先修 bug，再量天花板

**先发现一个真 bug（D14）。** 结果闸（Rule 4）声称"同一批 collision 再测一次"，实测代码没有重测：
`try_grow` 用**存储的旧答案**做 before/after，而旧答案属于**增长前**的图 ⇒ `after == before` 恒成立 ⇒
**闸门在构造上永远回滚**，"30/30 回滚"里有相当一部分是闸门缺陷而不是测量结果。
修法（根因）：结果闸改为 `_fresh_collision()`——**在当前图上把存储情境逐一套解一遍**再算余弦；
情境的驱动量随记忆一起存（`(present,context) → drive`），增长后按新神经元数补零列。
修后 90 次尝试（3 读出×30）全部回滚，但这次是**测出来的**。

**再量天花板。** 把生成器放到一边，手工搭最有利的修复：
- 从两个上下文细胞（ASH）直连 10 个读出细胞，**20 条边、权重扫两个数量级**：collision 从基线 **0.999689** 最好只降到 **0.996317**（降 **0.0034**）；
- 手工"修复神经元"（读上下文→写读出）：**0.999999**，毫无帮助。
判决所需降幅是 **0.02**。⇒ 在这张接线 + 这个读出 + 这个工作点上，**该家族里任何干预都不可能达标**；
负结果属于**基底**，不属于生成器。这条把 ① 从"未关闭"变成"已测量、有机制"。

### ② 认证的强度边界 —— 算术缺口关闭

认证界原本只对"算出来的矩阵"成立。现在矩阵在取比值前**整体外向膨胀 16ε（3.55e-15 相对）**，
见证不等式 `assert`：默认 efficacy **0.529065**、声明工作点 **0.931159**，二者不变。
⇒ 算术层的缺口**关闭**（界覆盖到模型的 3.55e-15 相对精度以内）；
剩下"模型 vs 生物系统"的差距是本论文的前提假设，不是可修的计算缺陷。

### ③ 缺 baseline —— 补上三条臂

同一预算 30 次尝试：

| 臂 | 增长前 collision | 平均 Δ | 最好 Δ |
|---|---|---|---|
| 生成器（伙伴取自差异细胞邻域） | 1.000000 | **+0.000100** | +0.000100 |
| 打乱（伙伴均匀随机） | 1.000000 | **+0.000100** | +0.000100 |
| 不增长（漂移地板） | 0.999873 | 0.000000 | 0.000000 |

⇒ 两条臂**完全一致**：在这张图上"差异驱动布线"**没有可测优势**（都让 collision 略有变差）。
因此论文对生成器的表述保持为**参数计数事实**（13 基因 vs 3137 突触类），
并明写"本文没有检验同维度的密集搜索会更差"。③ 关闭为"已测、无优势"。

### ④ 正面案例（本轮实现，结果是可界定的负）

把"跳过的那条"做完：**做一张考核机制本身的基底**——世界要区分的东西**存在但没有任何通路到读出**（结构可塑性的教科书用例）。

- 在接线后追加两个输入细胞 `context_tone`，**不发出任何边**，用它当上下文：两情境在**全状态**上相差 **6.5e-2 ~ 1.06e-1**（前提成立），读出 collision 仍 **1.000**（需求成立）。
- 生成器可以**直接读这两个细胞**（它们就是差异细胞），并可向读出投影：**60 次尝试**分四档新突触尺度（3/6/10/20 × 均值）× 兴奋/抑制两种投影，**全部回滚，collision 三位小数不变**。
- 原因已测且局部：**读出的细胞压在整流 sigmoid 的上限**，外加兴奋电流不可见，抑制又不足以把它拉出饱和。

同时修正两处设计（本轮）：**前提门改为"全状态差分"**（`min_state_motion`），因为按"读出是否已动"判会把**结构可塑唯一有意义的场景**（区别在网内、但无路到读出）拒之门外；**生成器的入边优先取自全状态差异细胞**（`difference_share`），并允许直接读它们——原来只从读出的答案里取差异，答案近似成比例时等于在复制答案。

### ⑤ 设计空间扫到底（本轮实现，共 330 次增长尝试，全部回滚）

"单元测试"通过后仍嫌不够，于是把**机制自己的设计空间扫到底**并逐一记录：

| 轴 | 取值 | 尝试 |
|---|---|---|
| 基底 | 线虫（3 种读出）、tone 单元测试 | 90 + 60 |
| 前提门 | 聚合 spread / 读出成对量 / **全状态差分**（最终） | — |
| 生成器取差异处 | 读出答案 / **全状态**（最终，含直接从差异细胞入边） | — |
| 新突触尺度 | 3 / 6 / 10 / 20 × 均值 | — |
| 投影符号 | 兴奋 / **抑制** | — |
| 工作点 | row_sum 0.5 / 1 / 2 / 4，输入尺度 1 / 3 / 10 | 120 |
| 动力学 | 库的标量模型 / **逐神经元异质**（`ep4nn/hetero.py`，自检通过：32 sweep、164/302 活跃） | 60 |

**结果：330 次尝试，0 次保留。** 关键新发现（来自 regime 筛查）：决定"修复能否被看见"的量是**答案细胞的局部响应增益**——
低于阈值与压在上限**同样聋**；而增益不为零的那条窄带里，collision 仍是 1.000。

**飞蝇嗅觉叶基底：已验证不可达（不是跳过）。** 库的 fly 航道是唯一"前提本来就成立"的候选（其文档实测 per-class gain 后 cosine 0.32），
但**发布物里没有连接组数据**：`cadence-demos/connectome` 只有 README/docs/receipts/tests/tools/web，无数据文件；
库自身 `docs/connectomes.md` 也不含任何数据集 URL（仅一个指向该 demo 仓的链接）。已把这条写成**已核验的限制**，并给出可核验的证据。

### 闭环后仍然不成立的宣称（继续不宣称）

- 增长收益：**仍无**——天花板 0.0034 < 阈值 0.02，是基底问题；论文与站点均不宣称收益。
- 认证：仍是"给定模型、给定状态"的局部界；12 状态域是测出来的区域，不是定理适用范围。
- 生成器优势：**未证实**（③ 的两臂一致），表述已限定为计数事实。

## 六、最初的缺口清单（保留原文，便于对照）

以下为第一版审计的原始条目，处理结果见上表。

- **G1 证书的"认证"强度**：`0.529/0.931` 是浮点特征值 + 幂迭代得到的**数值**界，没有区间算术或定向舍入保证；论文措辞应停在"数值证书（numerical certificate）"，不能说成 verified 界。
- **G2 局部性**：证书只在**该状态**成立（93.7% 神经元活跃）；换驱动、换增益需重算。原稿已写 remark 承认，但未给"多大扰动后失效"的界。
- **G3 前提门的规格弱点（设计层，最值得改的一条）**：前提用**聚合 spread** 判"读出会不会动"，而真正的判据应是**"世界声明必须区分的那一对"的成对可分性**。反例就在自家数据里：同一张图，不同情境集合给出 spread 0.019（grow demo）与 0.0372（扫描），聚合量随情境集合漂移。建议把前提闸改为成对判据（对每个 declared pair 要求 cosine ≤ code_cap），spread 只作诊断量。
- **G4 增长收益完全未测**：`kept=0`，论文已明写不宣称；但这也意味着"证据驱动的结构可塑"这条主线仍**只有机制没有功效**。
- **G5 对照强度**：随机图单种子、单状态谱对照；"13 基因 vs 3137 边"缺 dense-search baseline（该推断应降级为计数陈述，已按此改）。
- **G6 引用**：Shiu 2024 / Vaxenburg 2025 以"被 X 引用"的形式给出（未拿到一手条目）；BANC v888 的 150,802/1,877,099 未回到发布页逐字核对。按纪律：能核的核，核不到的只印已确认的形式。
- **G7 复现对比**：没做 snapshot → 重跑 → `diff -rq` 的空 diff 证明。所有数字是当场重跑得到的，但"提交的产物 == 重跑产物"这一步仍未做。
