# ep4nn 详细方案

从 302 神经元起步、按证据增补结构的**阶段化**方案。每阶段：目标 / 判据 / 接口 / 验收 / 成本 / 风险 / 依赖。
先给 8 条贯穿性决策（R1–R8），再给阶段，最后给 benchmark 与收据格式、以及明确不做的事。

---

## R1–R8：贯穿性设计决策

| # | 决策 | 理由（证据） |
|---|---|---|
| **R1** | **规则族分岔**：对称/成对子网走 EP（free/nudged 对比），**有向真实接线走预测编码/推断学习**，禁止混用同一套收敛假设 | Cadence 自述："arbitrary directed imports need not satisfy that gradient contract"；有向图的精确梯度定理不存在 |
| **R2** | **前提闸优先于容量闸**：先问"答案动不动"（读出 spread），再问"答案够不够分"（碰撞余弦） | 实测：spread 0.019 时 1200/1200 次增长被拒；无此闸时 30 次无效增长 |
| **R3** | **工作点必须显式声明并测量**：连接组不带兴奋性；行归一化 `row_sum` / `calibrate_bias` / `select_gain` 三选一，且**校准必须验收"响应性"而非只验收"居中"** | 实测：原始计数行和上百 → 每 tick 1.25 s 永不收敛；强行把读出校准到 0.5 → 读出被钉死（spread 0.019） |
| **R4** | **增长必须能到达读出**：新神经元必须有一条指向读出群体的边（基因 `to_readout`） | 否则在数学上不可能改变答案，裁决定会回滚 |
| **R5** | **重建成本 O(nnz) + efficacy 按 key 迁移**；增长事件频率 = 相悖频率，不是 tick 频率 | 实测重建 ~1 ms（302→310）；key = `post*n + pre`，与库排序一致，迁移无损 |
| **R6** | **预算与节流**：`max_neurons` / `min_ticks_between` / `min_evidence`；上限先小后大 | 防止"噪声触发结构剧变"；证据门 3 次、间隔 40 tick |
| **R7** | **结算从"拒绝"改为"预算 + 兜底"**：用活动集证书给 k ≈ log(ε/δ)/log α，超时交付上一合格动作并打收据 | 控制回路要求"永远有动作 + 偏差可界"；实测证书在真实图上存在（α=0.696）而全局界不存在（88） |
| **R8** | **不宣称 + 声明价值来源**：规模≠能力；价值尺度是外生还是演化内生必须写明，它决定上限与验收 | therealfly 反例；RLHF 的奖励劫持是内生属性 |

## Phase 0 前提层（当前阻塞点，先做这个）

**目标。** 让读出（前进 AVB/PVC + 后退 AVA/AVD/AVE，10 个细胞）在声明的情境集上**真的有响应**。

**判据。** `readout_spread ≥ 0.05`（跨情境每个读出细胞 max−min 的均值），且
**"不同情境的读出码两两不可分"的比例下降**。只用这两个数，不看训练损失。

**接口（全部是库内现成件）。**
- `cadence.learning.calibrate_bias(brain, drives, {"forward": 0.5, "reverse": 0.5}, per_neuron=True)`
  —— 已接入 `grow.py::_rebuild`，并加了"哪种工作点更响应就选哪种"的裁决（raw vs calibrated）。
- `cadence.learning.select_gain(make, protocol, [...], sparsity_cap=...)` —— 按**细胞类别**选增益
  （果蝇线上正是这一步把 cosine 0.98 压到 0.32）；`Protocol` + `Levels` 声明训练事实与 held-out 事实。
- `cadence.learning.preflight(brain, outputs, plastic, drives)` —— 一次读全部陷阱：读出无响应、
  可塑性发送端编码被两个情境共用、缝太薄。**要求 `warnings == []` 才允许进入 Phase 1。**
  对照：在果蝇的实测连接组上 preflight 无警告，打乱接线上警告三次——这就是我们需要的对照口径。

**验收。** `probes/probe_readout_response.py`（待写，~40 行）：对 302 线虫图扫
`row_sum ∈ {0.2,0.5,1.0}` × 单元格增益 × 偏置校准，输出 spread 与 preflight 警告表；
达标配置写进 `grow.py` 的 `GrowthConfig`（作为 founder，保留对照）。

**实测结果（2026-10-14，`probes/probe_readout_response.py`）。** 扫了 60 个工作点（5 个 row_sum ×
3 个增益类别 × 4 个倍数，9 个情境）：最好的配置是 row_sum=0.5 + command 类增益 ×10，**spread 只有 0.0777**，
而所有"同输入不同上下文"的答案 cosine 仍是 **1.000**（秩一：差异只沿一个方向）；末位配置 spread = 0.0000
（9 个情境答案完全相同）。⇒ **Phase 0 未通过，且失败方式已明确：声明读出在当前动力学下不承载可分辨性。**
阻塞不在容量，所以增长层不应被启用（现版本会 `refused_no_response`）。
下一步三选一（成本递增）：① 换声明读出（改为中间群体或一跳下游）；② 换动力学（Shiu 2024 LIF 参数 + 异质性细胞类型）；
③ 按协议对 held-out 生理事实选增益（Cadence 在果蝇上的做法）。先用 ① 的收益/成本比最高。

**成本。** 每次配置约 10–50 次 solve × ~100 sweep × ~100 µs ≈ 1–5 s；总扫描 < 5 分钟。
**风险。** 线虫图在这套 rate 模型下可能**根本不存在**有响应的增益（那本身是结论：**该图不适合做读出**，
需要换读出群体或换动力学）。
**依赖。** 无。

## Phase 1 增长层（机制已实现，待 Phase 0 通过后验证成效）

**目标。** 出现第一次 **kept** 增长：同批碰撞余弦下降 ≥ 0.02，且 old-task 行为不退化。

**判据（四个数一起报）。**
1. 可区分性：碰撞对的最大 |cosine|（before → after）。
2. 稀疏度：活跃神经元比例（<1% 是果蝇图的实测参照）。
3. 收敛预算：settle 的 sweep 数 / 活动集证书 α。
4. 代价：每 tick 的 per-sweep µs、重建 ms、CSR 内存。

**接口。** `ep4nn/grow.py`：`EP4NN.tick()`（需求+证据）、`try_grow()`（裁决+回滚）、
`_grow()`（生成器）、`_rebuild()`（工作点 + 重建）、`_difference_cells()`（信息驱动）。

**验收。**
- `kept ≥ 1`，且每次 kept 的 `before→after` 可复核；
- **保留旧能力**：增长前后在同一组"旧情境"上的 readout spread 不下降（增长不许破坏已能分辨的东西）；
- 失败也要出数：`rolled_back` 计数 + 原因分类（无响应 / 预算耗尽 / 无改善）。

**成本。** 增长事件：重建 ~1 ms + 校准 ~1 s（可降为"仅首次校准"）。tick 成本与图规模成正比（见台账 §5）。
**风险。** 增长可能只是把噪声塞进读出（"看起来可分"）。**对策**：对照臂 = 同规模随机布线增长，
必须比它更好才算数（Cadence 自己就是这条口径：打乱接线的对照）。
**依赖。** Phase 0。

## Phase 2 结构先验（距离核 → 传输延迟）

**目标。** 把"一跳邻域"升级成真正的几何先验，让新结构有**模块化**而不是随机稀疏。

**步骤（顺序不可颠倒）。**
1. **位置作为元数据**（已有：线虫 `ap/dv`、果蝇 `atlas.json`）+ **距离核生成器**：
   p(伙伴) ∝ exp(−d²/2σ²)，σ 为一个基因。**只影响"谁可能连谁"**，不动现有的均衡契约。
2. **结构可塑的时间常数**是分钟级（突触生成/消除），所以它属于慢层：与快权重解耦，不参与 ms–s 闭环。
3. **传输延迟**是另一件事：加上延迟后 `v ← (1−dt)v + dt(W·act + c)` 变成泛函方程，
   Prop 3.8/3.10/3.11 的收缩证书全部作废 ⇒ 需要新的契约（时滞系统的谱/范数判据）。
   **在拿到新契约前不加延迟。**

**判据。** 加入距离核后，同样的碰撞在**更少的新增突触**下解决（效率），且新增结构的模块度可测
（聚类系数/路径长度相对同规模随机图）。
**验收。** 与 Phase 1 同四列数 + 一个"每解决一个碰撞所需的新增突触数"作为效率指标。
**风险。** 距离核若参数过多就违反 `dim(生成器) ≪ |E|`；σ 必须是一个基因，不是一张表。
**依赖。** Phase 1。

## Phase 3 演化层（内生价值尺度）

**目标。** 让"什么值得追"（arousal/多巴胺中心与地板/actor 速率/需求）由**选择**塑造，
而不是人手设的常量。

**接口（Cadence 现成）。** `evolve(fitness, genome, generations, population, keep, seed, mutate=genes(space))`
+ `ArousalConfig.space()` + `Brain.compose`。founder 缺省值天然是对照（MANIFESTO 强制）。

**三个可跑的度量（这就是"容量-复杂度测量包"的正确纵轴）。**
1. **相对 founder 增益**：固定外生 fitness，演化 N 代，比较（任务质量, 代价）帕累托前沿。
2. **滞后度量**：换 fitness（环境变更）后需要几代追上。
3. **可迁移性**：演化出的价值尺度换到新任务上是否更好——这条区分"学到普适动机"与"过拟合代理量"。

**判据。** 三项都要有数；若第 3 项为负，说明学到的是对评分的拟合（这正是要报出来的负结果）。
**风险。** fitness 始终由人给 ⇒ 上限=代理量。要么接受，要么把 fitness 换成不自证的
（物理存活/能量/复制，Patch World 的写法：跑脑要花质量，更大的脑必须自己挣回来）。
**依赖。** Phase 1（结构层稳定后再让价值层演化）。

---

## Phase 4 文化层（共享经验）

**目标。** 让个体的经历能跨个体传递（同代内传播，比代际快数个量级）。

**最小接口。** 一个**共享记录库**（Cadence 的 record 是线性、一次写、精确的，天然适合当共享层）+
每个脑在 startup 时读、在关键事件时写；写入门槛沿用 Phase 1 的证据门。
**判据。** 新个体在旧情境上的首次表现（收敛速度、碰撞数）显著好于无共享库的对照。
**风险。** 共享库会**同步偏见**（"梦忠实放大错误记忆"的社会版）——必须配一个"撤回"通道
（某个体的反例证据能删除共享条目），并记录每个条目的来源与证据数。
**依赖。** Phase 3。

## Benchmark 与收据格式（跨阶段统一）

**每个结果必须回答的六项**（这就是 `果蝇生态审阅.md` 里那张表缺的东西）：

```
dataset        : 数据源 + 版本 + sha256
nominal vs run : 名义规模 vs 本次实际运行的神经元/突触数
dynamics       : rate / LIF / 脉冲；参数表；有无延迟、适应、调质
loop           : 是否闭环；哪一步是外挂控制器；哪些是声明
premise        : 工作点、读出 spread、preflight 警告（前提是否成立）
cost           : 每次决策的 per-sweep µs、sweep 数、重建 ms、CSR 内存、能耗（若可测）
```

**四个核心量**（缺一不可）：可区分性（碰撞余弦 / 有效秩）· 稀疏度（活跃比例）·
收敛预算（sweep 数 / 证书 α）· 代价（算力与时延，能耗单列）。

## 明确不做

1. **不做"神经元数量"叙事**（规模 ≠ 能力，therealfly 反例）。
2. **不做无位置先验的"纯统计稀疏"当几何**（生物稀疏化 = 几何 + 增益 + 抑制，手里只有增益那件时别假装有几何）。
3. **不混用规则族**（对称 EP / 有向预测编码，R1）。
4. **不做带钱包的自主 web agent、不做币**（合规与信任风险；novelty 代替糖 = 伪目标）。
5. **不在没有新契约的情况下加延迟**（会把全部收敛证书作废）。
